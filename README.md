# Ishan Nepal – Personal Portfolio

Interactive personal portfolio of **Ishan Nepal** — BBS student at Kankai Adarsha Campus.

**Repo:** [github.com/SANJI0008/portfolio](https://github.com/SANJI0008/portfolio)  
**Live site (GitHub Pages):** [sanji0008.github.io/portfolio](https://sanji0008.github.io/portfolio/)

## Features

- Smooth micro-interactions (hover lifts, nav underlines, button press)
- Scroll-triggered fade / slide animations
- Typing effect in the hero
- Lightweight particle background
- Glassmorphism nav and cards
- Dark / light mode with system preference + persistence
- Fully responsive
- Contact form (opens your email client)

## Run locally

Open `index.html` in a browser, or:

```bash
python -m http.server 8000
```

No build step — Tailwind is loaded from the CDN.

## GitHub Pages

This site is static. Enable Pages:

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save — it will be live at `https://sanji0008.github.io/portfolio/`
